前回、黎蓮がこの話を書いた。

廷尉平・虞獻が朱貞に約束した。書類の奏上を一日待つ、と。しかし、酔って忘れてしまった。翌朝、書類は抜き取られることなく、束ごと帝の前に届いた。朱貞は死んだ。

今回は、その原文を一緒に開いていきたいと思う。

繁体字（原文）・簡体字・ピンイン・語義の順で、全文を読んでいく。難しく構えなくていい。「こんな字を使うんだ」「このピンイン、知ってる字と同じだ」——そういう感覚で、一段ずつ降りていけばいい。

出典は『還冤記（かんえんき）』——別名『冤魂志（えんこんし）』——第五十五条。維基文庫（Wikisource）所収テキストより。★★★

## 第一段——罪と審理、そして約束

繁体字（原文）：

> 梁秣陵令朱貞，以罪下獄。廷尉平虞獻考覈其事，結正入重。貞遣相知謂獻曰：「我罪當死，不敢祈恩，但猶冀主上萬一弘宥耳。明日即是國家忌曰，乞得過此奏聞，可乎？」獻答曰：「此於理無爽，何謂不然？謹聞命矣，而朱事先入明日奏束。」

簡体字：

> 梁秣陵令朱贞，以罪下狱。廷尉平虞献考核其事，结正入重。贞遣相知谓献曰：「我罪当死，不敢祈恩，但犹冀主上万一弘宥耳。明日即是国家忌日，乞得过此奏闻，可乎？」献答曰：「此于理无爽，何谓不然？谨闻命矣，而朱事先入明日奏束。」

ピンイン：

Liáng Mòlíng lìng Zhū Zhēn, yǐ zuì xià yù. Tíngwèi píng Yú Xiàn kǎohé qí shì, jié zhèng rù zhòng. Zhēn qiǎn xiāngzhī wèi Xiàn yuē: "Wǒ zuì dāng sǐ, bù gǎn qí ēn, dàn yóu jì zhǔshàng wàn yī hóng yòu ěr. Míng rì jí shì guójiā jì rì, qǐ dé guò cǐ zòu wén, kě hū?" Xiàn dá yuē: "Cǐ yú lǐ wú shuǎng, hé wèi bù rán? Jǐn wén mìng yǐ, ér Zhū shì xiān rù míng rì zòu shù."

語義：

| 語 | 簡体字 | ピンイン | 意味 |
|---|---|---|---|
| 以罪下獄 | 以罪下狱 | yǐ zuì xià yù | 罪によって獄に下される |
| 廷尉平 | 廷尉平 | Tíngwèi píng | 廷尉（皇帝直属の司法機関）の平（次席官） |
| 考覈 | 考核 | kǎohé | 精査する、審査する |
| 結正入重 | 结正入重 | jié zhèng rù zhòng | 重罪と確定した |
| 相知 | 相知 | xiāngzhī | 信頼できる知り合い（使者として送られた） |
| 祈恩 | 祈恩 | qí ēn | 恩赦を願う |
| 萬一弘宥 | 万一弘宥 | wàn yī hóng yòu | 万に一つ、広く赦してくださること |
| 國家忌日 | 国家忌日 | guójiā jì rì | 皇族の命日（この日は重大案件の決裁を慎む慣わし） |
| 乞得過此奏聞 | 乞得过此奏闻 | qǐ dé guò cǐ zòu wén | この日を過ぎてから奏上していただけないか |
| 於理無爽 | 于理无爽 | yú lǐ wú shuǎng | 道理に外れることはない（爽＝違背する） |
| 謹聞命矣 | 谨闻命矣 | jǐn wén mìng yǐ | 謹んで御命を承りました |
| 奏束 | 奏束 | zòu shù | 奏上する文書の束 |

「謹聞命矣（jǐn wén mìng yǐ）」——謹んで承りました、という言葉だ。「謹」の字には「慎む・丁寧に扱う」という含みがある。虞獻はちゃんと約束した。確かに、した。

## 第二段——酔いと忘却

繁体字（原文）：

> 獻便遇客共飲，頗醉，遂忘抽文書。旦日，家人合束，內衣箱中，獻復不記。比至帝前，頓束香案上，次第披之，方見此事，勢不可隱，便爾上聞。武帝以為合死。付外詳決。

簡体字：

> 献便遇客共饮，颇醉，遂忘抽文书。旦日，家人合束，内衣箱中，献复不记。比至帝前，顿束香案上，次第披之，方见此事，势不可隐，便尔上闻。武帝以为合死。付外详决。

ピンイン：

Xiàn biàn yù kè gòng yǐn, pō zuì, suì wàng chōu wénshū. Dàn rì, jiārén hé shù, nèi yī xiāng zhōng, Xiàn fù bù jì. Bǐ zhì dì qián, dùn shù xiāng àn shàng, cì dì pī zhī, fāng jiàn cǐ shì, shì bù kě yǐn, biàn ěr shàng wén. Wǔdì yǐwéi hé sǐ. Fù wài xiáng jué.

語義：

| 語 | 簡体字 | ピンイン | 意味 |
|---|---|---|---|
| 遇客共飲 | 遇客共饮 | yù kè gòng yǐn | たまたま客と飲み合わせた |
| 頗醉 | 颇醉 | pō zuì | かなり酔った |
| 忘抽文書 | 忘抽文书 | wàng chōu wénshū | 文書を抜き取るのを忘れた |
| 旦日 | 旦日 | dàn rì | 翌朝 |
| 家人合束 | 家人合束 | jiārén hé shù | 家人が書類をひとまとめにした |
| 獻復不記 | 献复不记 | Xiàn fù bù jì | 虞獻もまた気づかなかった |
| 比至帝前 | 比至帝前 | bǐ zhì dì qián | 帝の御前に至ると |
| 頓束香案上 | 顿束香案上 | dùn shù xiāng àn shàng | 文書の束を香案（文机）の上に置いた |
| 次第披之 | 次第披之 | cì dì pī zhī | 一枚一枚めくっていった |
| 勢不可隱 | 势不可隐 | shì bù kě yǐn | もはや隠すことができない |
| 便爾上聞 | 便尔上闻 | biàn ěr shàng wén | そのまま上奏された |
| 以為合死 | 以为合死 | yǐwéi hé sǐ | 死罪に相当すると判断した |
| 付外詳決 | 付外详决 | fù wài xiáng jué | 外（廷尉）に委ねて詳しく処決するよう命じた |

「次第披之（cì dì pī zhī）」——次（cì）＝順番に、第（dì）＝順序、披（pī）＝広げる・めくる、之（zhī）＝それを。一枚一枚、めくっていく。その指が朱貞の文書に触れた瞬間、事態は変えられなくなった。

## 第三段——朱貞の言葉

繁体字（原文）：

> 貞聞之，大恨曰：「虞小子，欺罔將死之人。鬼若無知，固同灰土；儻其有識，必報之。」貞於市始當命絕，而獻已見其來。自爾之後，時時恆見，獻甚惡之。又夢乘車在山下行，貞於山上推石壓之。

簡体字：

> 贞闻之，大恨曰：「虞小子，欺罔将死之人。鬼若无知，固同灰土；倘其有识，必报之。」贞于市始当命绝，而献已见其来。自尔之后，时时恒见，献甚恶之。又梦乘车在山下行，贞于山上推石压之。

ピンイン：

Zhēn wén zhī, dà hèn yuē: "Yú xiǎozǐ, qī wǎng jiāng sǐ zhī rén. Guǐ ruò wú zhī, gù tóng huī tǔ; tǎng qí yǒu shí, bì bào zhī." Zhēn yú shì shǐ dāng mìng jué, ér Xiàn yǐ jiàn qí lái. Zì ěr zhī hòu, shí shí héng jiàn, Xiàn shèn wù zhī. Yòu mèng chéng chē zài shān xià xíng, Zhēn yú shān shàng tuī shí yā zhī.

語義：

| 語 | 簡体字 | ピンイン | 意味 |
|---|---|---|---|
| 大恨 | 大恨 | dà hèn | 激しく憤る |
| 虞小子 | 虞小子 | Yú xiǎozǐ | 虞よ（小子は軽蔑・怒りを込めた呼称） |
| 欺罔 | 欺罔 | qī wǎng | 欺く、騙す |
| 將死之人 | 将死之人 | jiāng sǐ zhī rén | 死にゆく者 |
| 鬼若無知 | 鬼若无知 | guǐ ruò wú zhī | 鬼（死者の霊）に知覚がなければ |
| 固同灰土 | 固同灰土 | gù tóng huī tǔ | 灰土と変わらない（それで構わない） |
| 儻其有識 | 倘其有识 | tǎng qí yǒu shí | もし鬼に識（知覚・意識）があるなら |
| 必報之 | 必报之 | bì bào zhī | 必ずや報いを受けさせる |
| 於市始當命絕 | 于市始当命绝 | yú shì shǐ dāng mìng jué | 市（刑場）で処刑された瞬間 |
| 自爾之後 | 自尔之后 | zì ěr zhī hòu | それ以来 |
| 時時恆見 | 时时恒见 | shí shí héng jiàn | 繰り返し（朱貞の姿が）見え続けた |
| 甚惡之 | 甚恶之 | shèn wù zhī | ひどく嫌悪した、おそれた |
| 推石壓之 | 推石压之 | tuī shí yā zhī | 石を転がして（自分に）押しかけてくる |

「儻（tǎng）」——「もしかしたら」という字だ。儻其有識——もし鬼に知覚があるなら。この一字に、朱貞の怒りと疑いの両方が入っている。死後の世界があるかどうかはわからない。それでも、もしあるなら必ず報いる、と言い切った。確信ではなく、問いかけだ。しかし「必報之」で終わる。

## 第四段——崩壊の連鎖

繁体字（原文）：

> 居月餘，獻除曲阿令，拜之明日。詣謝章門下。其婦平常，於宅暴卒，獻狼狽而還，入室哭婦，舉頭見貞在梁上，獻曰：「朱秣陵在此，我婦豈得不死！」於時屋無故忽崩，獻及男女婢使十餘人，一時併命。右丞虞騭是其宗室，助喪事，見獻還，暫下堂避之，僅乃得免。

簡体字：

> 居月余，献除曲阿令，拜之明日。诣谢章门下。其妇平常，于宅暴卒，献狼狈而还，入室哭妇，举头见贞在梁上，献曰：「朱秣陵在此，我妇岂得不死！」于时屋无故忽崩，献及男女婢使十余人，一时并命。右丞虞骘是其宗室，助丧事，见献还，暂下堂避之，仅乃得免。

ピンイン：

Jū yuè yú, Xiàn chú Qūā lìng, bài zhī míng rì. Yì xiè zhāng mén xià. Qí fù píngcháng, yú zhái bào zú, Xiàn lángbèi ér huán, rù shì kū fù, jǔ tóu jiàn Zhēn zài liáng shàng, Xiàn yuē: "Zhū Mòlíng zài cǐ, wǒ fù qǐ dé bù sǐ!" Yú shí wū wú gù hū bēng, Xiàn jí nánnǚ bì shǐ shí yú rén, yī shí bìng mìng. Yòuchéng Yú Zhì shì qí zōngshì, zhù sāng shì, jiàn Xiàn huán, zàn xià táng bì zhī, jǐn nǎi dé miǎn.

語義：

| 語 | 簡体字 | ピンイン | 意味 |
|---|---|---|---|
| 居月餘 | 居月余 | jū yuè yú | 一ヶ月余り経って |
| 除曲阿令 | 除曲阿令 | chú Qūā lìng | 曲阿の令（長官）に任命された |
| 拜之明日 | 拜之明日 | bài zhī míng rì | 拝礼（就任式）の翌日 |
| 詣謝章門下 | 诣谢章门下 | yì xiè zhāng mén xià | 宮門への挨拶に赴いた |
| 暴卒 | 暴卒 | bào zú | 突然死んだ |
| 狼狽而還 | 狼狈而还 | lángbèi ér huán | 慌てふためいて帰った |
| 梁上 | 梁上 | liáng shàng | 梁（はり）の上 |
| 朱秣陵 | 朱秣陵 | Zhū Mòlíng | 朱（秣陵令）——官職名を添えた呼び方 |
| 豈得不死 | 岂得不死 | qǐ dé bù sǐ | どうして死なないでいられよう（死ぬのは当然だ） |
| 無故忽崩 | 无故忽崩 | wú gù hū bēng | 理由なく突然崩れ落ちた |
| 男女婢使 | 男女婢使 | nánnǚ bì shǐ | 家の男女と奴婢 |
| 一時併命 | 一时并命 | yī shí bìng mìng | 同時に命を失った |
| 右丞 | 右丞 | yòuchéng | 廷尉右丞（官職名） |
| 宗室 | 宗室 | zōngshì | 同族 |
| 暫下堂避之 | 暂下堂避之 | zàn xià táng bì zhī | しばらく堂を降りて避けた |
| 僅乃得免 | 仅乃得免 | jǐn nǎi dé miǎn | ようやく難を免れた |

「無故忽崩（wú gù hū bēng）」——理由（故）なく（無）突然（忽）崩れ落ちた（崩）。四字で書いている。説明はない。記録はそれだけを書いて、次へ進む。

## 読み終えて

ここまで付き合ってくれてありがとう。

原文で読むと、「約束」と「忘却」がどれだけ短い言葉で書かれているかわかる。「謹聞命矣」——承りました——五字。「頗醉，遂忘抽文書」——かなり酔って、文書を抜き取るのを忘れた——九字。約束から忘却まで、合わせて十四字。それだけで朱貞の死が決まっていく。短いから軽いわけじゃない。短いから重い。

もう一つ、「儻（tǎng）」という字を覚えておいてくれ。「もしかしたら」「万が一」という意味だ。儻其有識——もし亡霊に識があるなら。この一字が、朱貞の言葉に揺れを入れてる。確信じゃない。なのに「必報之」で終わる。そこがぞっとするんだよ。
